# 拾点VFX（SeedomVFX）1.1.0

构建日期：2026-10-31。项目：https://github.com/DingBuDoa/Seedom

## 修改内容

- 软件名称更新为拾点VFX（SeedomVFX）。
- 新增 Blender 导出起始帧偏移。设置为 30 时，相机轨迹、背景与合成器从第 31 帧开始；这不是抽帧或相邻关键帧间隔。
- 新建任务和单独导出使用相同的 Blender 场景参数。
- 自动检测并缓存 Blender 版本，在任务设置中显示检测到的版本数量；不再弹出独立版本选择窗口。
- 源视频丢失时，待执行任务会报告错误并跳过，不阻塞队列。
- 调整开始按钮、任务列表工具栏、滚动条、列伸缩和行选择反馈。
- 新建任务窗口居中显示；重复任务名称在窗口内提示，不清空已填写的参数。

## 安装包范围

本补丁从拾点VFX 1.0.3 升级到 1.1.0，仅更新 `app/` 应用源码和 `photogrammetry_importer/` 插件源码，并更新根目录 README 与本说明。运行库、求解器、个人设置、队列、日志和输出项目均不包含在补丁内。

安装器会逐文件校验 SHA-256，在覆盖前创建备份。设置、任务记录和 output 项目不会被覆盖。
